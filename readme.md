# Credit Card Fraud Detection Using Machine Learning

## Project Description
This project demonstrates credit card fraud detection
using a Machine Learning classification model.

## Objectives
- Identify suspicious transactions.
- Classify transactions as genuine or suspicious.
- Demonstrate machine learning predictions.

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- HTML
- CSS

## Features
- User-friendly web interface.
- Transaction amount input.
- Transaction count input.
- Fraud prediction results.

## Project Files
- app.py - Main Python application.
- README.md - Project documentation.

## How to Run
1. Install the required Python libraries.
2. Open the project folder in VS Code.
3. Run: py app.py
4. Open http://127.0.0.1:5000 in your browser.

## Note
This is an educational demonstration using a small
sample dataset. It is not validated for real-world
credit card fraud detection.
